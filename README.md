# Avaliador de Marcas 🏷️📊

Projeto acadêmico desenvolvido em **Python** durante a graduação em **Análise e Desenvolvimento de Software** na **Faculdade Estácio**.

O sistema permite cadastrar marcas, registrar avaliações de usuários e visualizar estatísticas por meio de gráficos, utilizando interface gráfica e banco de dados local.

---

## 📌 Funcionalidades

- Cadastro de marcas (nome, estilo e origem)
- Edição e remoção de marcas cadastradas
- Avaliação de marcas por usuários (nota de 1 a 5 e comentário)
- Armazenamento dos dados em banco **SQLite**
- Listagem de avaliações registradas
- Geração de gráficos:
  - Média de avaliações por marca
  - Distribuição de estilos das marcas

---

## 🛠️ Tecnologias Utilizadas

- **Python**
- **Tkinter** (interface gráfica)
- **SQLite3** (banco de dados local)
- **Matplotlib** (visualização de dados)

---

## 🧠 Conceitos Aplicados

- Lógica de programação
